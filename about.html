About Me

Who I Am

I am a dedicated Software Developer with a strong foundation in modern web technologies. My passion lies in building functional, visually appealing, and scalable applications. I have immersed myself deeply in both front-end and back-end development.

My goal is to continuously grow as a full-stack developer and build solutions that matter.

Learning Journey

Here is a comprehensive overview of the 12-week Web Development Course I have undertaken, which provided me with a solid foundation in front-end and back-end technologies.

Weeks 1-2 Intro & Linux

Overview of web development is grasping the absolute basics of HTML and CSS.

Weeks 3-4 Advanced HTML/CSS

In-depth lessons on semantic HTML5, advanced CSS3 techniques (Flexbox, Grid).

Weeks 5-6 JS Fundamentals

Core concepts of JavaScript, including functions, control flow, DOM manipulation, and asynchronous programming (Promises, async/await).

Weeks 7-8 Front-End Frameworks

Introduction to React.js. Focused on components, props, state management, hooks, and modern styling techniques.

Weeks 9-10 Node.js & Back-End

Fundamentals of Node.js. Building RESTful APIs with Express.js, middleware, and integrating MongoDB for robust data persistence.

Weeks 11-12 Full-Stack & Deploy

Combining front-end and back-end to create complete applications. Best practices for testing, Git version control, and cloud deployment.
